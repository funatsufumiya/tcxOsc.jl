# tcxOsc.jl

tcxOsc of [TrussC](https://trussc.org/) [Julia](https://julialang.org/) binding.

C++ bindings are generated by [tcxOscJlWrap](https://github.com/funatsufumiya/tcxOscJlWrap) using [CxxWrap.jl](https://github.com/JuliaInterop/CxxWrap.jl) (and it's precompiled in [tcxOsc_prebuilt_jll](https://github.com/funatsufumiya/tcxOsc_prebuilt_jll))

> [!NOTE]
> This repository is not registered in public package manager, so you need `pkg> add https://github.com/xxx/yyy.git` (see [How to add this library into your project](#how-to-add-this-library-into-your-project) in detail)

## How to add this library into your project

In your project, run `julia --project=@.` and:

- `pkg> add https://github.com/funatsufumiya/tcxOsc_prebuilt_jll.git`
- `pkg> add https://github.com/funatsufumiya/tcxOsc.jl.git`

(NOTE: `pkg>` REPL can be shown by typing `]` key on julia REPL, and type Backspace key to back to normal REPL.)

## Dependencies

- https://github.com/funatsufumiya/tcxOsc_prebuilt_jll
